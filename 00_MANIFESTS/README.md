# Manifest guide

- `PRE_REORGANIZATION_FILE_INVENTORY_SHA256.json`: every file present before reorganization.
- `POST_REORGANIZATION_FILE_INVENTORY_SHA256.json`: canonical-root inventory immediately after moving existing materials.
- `REORGANIZATION_ACTIONS.json`: source, destination, reason, and recoverability for every move.
- `AJSE_CANONICAL_ROOT_STATUS.json`: canonical task boundary and current Phase 2A result status.

All hashes use SHA-256.
