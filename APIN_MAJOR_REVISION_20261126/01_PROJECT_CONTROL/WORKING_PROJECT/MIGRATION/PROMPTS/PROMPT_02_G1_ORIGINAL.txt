# 8. E02：交通状态、数据缺失及可靠性分析

E02主要复用原始FCD、小时面板、可靠性特征和冻结预测。

不得重新训练模型。

## E02-01：速度及目标分布

分别计算筛选前、质量合格及正式小时面板中的：

- Current speed。
- Free-flow speed。
- 预测目标H1、H3、H6。
- Mean。
- Median。
- Standard deviation。
- Minimum。
- Maximum。
- P5、P25、P75、P95。
- 样本数。

报告各节点及整体分布。

区分返回行级、去重15分钟级、小时级和预测目标级统计。

不得混用统计层级。

## E02-02：自由流速度一致性分析

计算current speed与free-flow speed：

- 完全相等的比例。
- 绝对差值分布。
- 相差不超过1 km/h的比例。
- Current speed/free-flow speed比例分布。
- 不同节点的自由流一致性。
- 不同confidence水平下的自由流一致性。

仅在free-flow speed为有限正数时计算比值。

单独登记异常及无法计算的记录。

不得直接将接近自由流解释为真实道路没有拥堵。

不得仅凭速度相等比例推断TomTom一定使用了历史速度回填。

## E02-03：Confidence分布

报告：

- 筛选前confidence分布。
- confidence低于0.80的记录。
- 质量合格记录的confidence分布。
- confidence与速度比值的关联。
- 不同时段和节点的confidence差异。

建议冻结分组：

- confidence < 0.80。
- 0.80 ≤ confidence < 0.90。
- 0.90 ≤ confidence < 1.00。
- confidence = 1.00。

区分缺失、无效和范围外数值。

不得把供应商confidence等同于经过独立验证的统计置信概率。

## E02-04：交通状态划分

采用供应商报告速度与自由流速度的比例：

r = current_speed / free_flow_speed

候选工程分类固定为：

- r < 0.70：Congested proxy。
- 0.70 ≤ r < 0.90：Intermediate traffic state。
- r ≥ 0.90：Near/free-flow proxy。

这些阈值属于本研究预设的操作化诊断定义，不宣称是普遍适用的交通工程标准。

增加一次有限阈值敏感性检查，例如拥堵阈值0.60、0.70、0.80。

其他规则保持不变。

不进行大量阈值搜索，不依据模型结果选择最有利的阈值。

预测样本的未来窗口交通状态应当由与目标对应的有效小时速度及free-flow speed计算。

优先采用目标窗口有效小时平均速度除以相同有效小时平均自由流速度。

明确H6 5/6规则下只使用对应目标的有效小时。

未来窗口交通状态仅用于事后误差诊断，不得作为预测origin时刻可用的模型特征。

## E02-05：自由流与拥堵状态模型性能

使用六模型相同预测样本，分别计算H1、H3、H6在各交通状态下的：

- Sample count。
- MAE。
- RMSE。
- Bias。

## E03-01：随机种子聚合口径专项核验

原论文Equation (12)说明：

先对XGBoost和GRU的三个随机种子预测进行逐样本平均，再计算MAE。

但G0工作簿的E03准备度记录提出，原主结果可能采用先计算逐seed指标、再平均指标的方式。

这两种方法数学上并不等价。

必须对XGBoost与GRU分别计算：

方法A：Ensemble prediction MAE。

先按共同样本主键平均三个预测值，再计算MAE。

方法B：Mean seed-level MAE。

先计算每个seed的MAE，再平均三个MAE。

分别按6个fold和H1、H3、H6输出结果。

计算完整的六模型 × 三horizon × 六fold结果及相应fold-macro汇总。

与原稿Table 7、原始指标注册表及历史审计记录对照。

输出：

- manuscript_reported_value。
- method_A_value。
- method_B_value。
- difference_A_vs_reported。
- difference_B_vs_reported。
- best_supported_original_definition。
- discrepancy_status。
- explanation。

原稿Table 7使用三位小数时，应考虑正常四舍五入容差；优先与未舍入的历史指标对照。

不得单凭四舍五入后某一数值相近就确认全部原始实现。

如果A和B均无法完全对应历史指标，保留差异，不继续无边界搜索。

本阶段新的主要模型比较口径预设为方法A，即Equation (12)所定义的逐样本ensemble预测。

方法B作为种子层面的补充结果。

如果原表实际采用方法B，必须报告论文描述与计算实现不一致，并登记后续正文和结果修正事项。

不得根据哪种方法更有利于XGBoost而改变主要口径。

## E03-02：共同样本及逐样本配对损失

实际读取180份预测，利用历史验收证据及本阶段必要关联检查建立统一配对损失表。

主键至少包括：

- fold。
- horizon。
- sample_id。
- node_id。
- forecast_origin。

核对：

- 模型间样本主键一致。
- 目标值一致。
- 预测值为有限数值。
- 三个seed均存在。
- seed顺序及身份正确。
- 不存在多对多连接。

统一计算：

- Absolute error。
- Squared error。
- Signed error。
- Paired absolute-loss difference。

模型A减模型B的损失差：

d = absolute_error_A − absolute_error_B

负值表示模型A误差较低。

正值表示模型B误差较低。

配对明细仅保存在受控本地目录，不纳入对外审查ZIP。

## E03-03：原始基准与统计权重分解

同时输出以下估计量：

### Estimand 1：Fold-macro

每个fold内部计算MAE，再对六个fold等权平均。

用于原投稿结果对照。

### Estimand 2：Sample-weighted

对所有共同预测样本等权汇总。

用于说明每条有效预测记录的平均误差。

### Estimand 3：Day-macro

- 实际样本数。
- 日期数。

## E03-04：依赖感知的统计不确定性

原六fold精确双侧Wilcoxon的统计设计存在已知功效限制：

最小未校正p值 = 2/2^6 = 0.03125。

每个horizon进行5项Holm比较时，最小可达到的首项校正值为0.15625。

因此原检验不能作为“模型没有差异”或“模型等效”的证据。

保留原统计结果用于说明历史方法限制，不再将其作为主要推断方法。

### 主要统计方案

使用每日配对损失差序列。

优先采用Moving Block Bootstrap：

- 重采样单位：连续当地日期组成的时间块。
- 同一日期内部所有共同样本和节点整体保留。
- 主要块长度：3个连续日期。
- 敏感性块长度：7个连续日期。
- 重采样次数：10,000。
- 固定随机种子：20261125。
- 置信区间：双侧95% percentile interval。

上述块长度为本阶段预先规定的有限分析方案，不宣称已经证明是最优块长度。

首先检查真实日期支持、缺失日期及fold边界。

不能将不存在的日期当作有效日期，也不能将跨越真实观测中断的日期拼接成连续时间块。

在协议中明确连续测试日期跨fold边界的处理及日期有效性定义。

若某horizon不能形成足够的连续日期块，应标记INFERENCE_LIMITED，保留描述性效应，不强行生成看似可靠的显著性结论。

主要Bootstrap估计对象为Day-macro配对损失差。

需要明确：

- 日与日之间仍可能相关。
- 不同fold对应不同训练后的模型。
- 仅有约41个测试日期，独立有效信息仍然有限。
- 保留空间节点整体的日期块只能缓解部分依赖问题，不能解决所有依赖。

### 补充统计方案

如每日损失差序列支持，可进行有限HAC/Diebold-Mariano类型敏感性分析。

必须先确认：

- 每日损失差定义。
- 日期连续性。
- 有效样本数量。
- 方差估计条件。
- 时间相关性处理。

若执行HAC，预先固定候选lag，例如3个日期，不根据p值选择。

不要求必须获得显著结果。

如果相关假设无法合理支持，输出NOT_APPLICABLE及原因。

不得将G1变成重复的全面数据审计。

## G1-A：E01验收标准

- 数据分母、分子及统计层级明确。
- 正式网格时间范围正确。
- 原始返回行与唯一槽位不混淆。
- 行级和槽位级漏斗计算可追溯。
- 四种小时资格规则计数正确或差异有解释。
- H6完整与不完整目标样本可追溯。
- 缺失位置统计完整。
- 各fold样本剔除及保留数量明确。
- 没有对无观测目标进行虚构插补。
- 97.30%问题明确登记后续修正方案。

## G1-B：E02验收标准

- Current speed、free-flow speed及confidence字段正确。
- 自由流比例及交通状态计算有真实数据支持。
- 所有误差评价使用对应有效目标。
- 样本选择偏差仅基于可观测证据。
- Coverage、Gap及Volatility定义与原研究对应。
- 所有分层结果报告样本支持。
- Road closure不可估计的情况被如实记录。
- Free-flow baseline满足预测时点的信息可得性约束，或明确标记受限。
- 不将供应商速度称为独立真实速度。

## G1-C：E03验收标准

- 两种seed聚合口径均已计算。
- 原Table 7差异得到定位或明确记录。
- 共同样本主键和真值一致。
- 新统计估计量定义清晰。
- 时间及空间依赖处理有明确限制说明。
- Bootstrap协议提前冻结。
- 原15项比较完整保留。
- Holm校正正确或无法推断情况已登记。
- LOFO完整报告六种排除情况。
- 不以获得统计显著性作为验收通过条件。
- 不将回顾性结果称为独立盲测。

## G1-D：验收状态

每个子任务使用：

- PASS。
- CONDITIONAL_PASS。
- NOT_ESTIMABLE。
- BLOCKED。

其中：

NOT_ESTIMABLE表示数据结构或观测条件确实无法回答该科学问题，并不表示必须追加新的数据。

例如，没有观测到道路封闭事件，不能估计封闭效应。

总体G1采用：

- PASS。
- CONDITIONAL_PASS。
- BLOCKED。

必须依据实际结果判定。

不要为了获得PASS而隐瞒差异、数据缺失、不显著结果或模型排名反转。
