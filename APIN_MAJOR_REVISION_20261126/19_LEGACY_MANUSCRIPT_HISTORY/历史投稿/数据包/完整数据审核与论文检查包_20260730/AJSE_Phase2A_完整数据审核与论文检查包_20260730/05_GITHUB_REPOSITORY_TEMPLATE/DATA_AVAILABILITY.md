# Data Availability

The source traffic records were obtained from a commercial floating-car-data provider. Redistribution of raw provider responses is not assumed to be permitted.

The public repository may provide:

- data dictionaries;
- theoretical time-grid definitions;
- anonymized or aggregated sample data;
- frozen sample manifests where licensing permits;
- model and evaluation configurations;
- preprocessing and audit code;
- aggregated metrics and statistical results;
- figures, tables, checksums and audit reports.

The following must not be uploaded without explicit permission:

- raw commercial API responses;
- API keys and credentials;
- provider-restricted records;
- confidential node metadata;
- private local paths or environment secrets.
