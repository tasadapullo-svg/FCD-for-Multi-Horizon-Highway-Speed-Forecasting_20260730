# E08 决策：NOT_FEASIBLE_WITH_CURRENT_DATA

工程内仅见原 Pan Borneo 商业 FCD 包，无同走廊后续独立时期或其他走廊的合格归档。R1-08 的测试集历史暴露和 R2-04 的独立评价时期因此不能宣称解决；R2-01 跨道路泛化、R3-12 同址真实速度也未验证。

唯一公开候选 METR-LA 为美国固定环路检测器速度序列，项目原始 DCRNN README 给出 HDF5 下载入口；仓库 MIT 仅能证明代码许可，不能据此认定数据可再分发。原文件的精确日期、速度单位、零值/缺失定义、大小尚需下载后核验。人工模拟缺失只能测试算法压力，不能验证商业 FCD 的真实返回机制，也不能验证 Pan Borneo 同址真实速度。

若作者随后确认合法获取并批准 E08：只取一个 METR-LA 数据集；按原时间顺序划分独立测试段；由5分钟序列构造真实观测小时与 H1/H3/H6 未来窗口平均目标，共同样本比较 SeasonalHA、Persistence、XGBoost、GRU；冻结原模型选择规则，只允许数据维度适配，不复制 E04–E06 全部实验；记录传感器数、有效小时、真实缺失、训练/测试边界、机器耗时。预计需数十次模型拟合，预算须在文件级数据核验后确定。不得将该结果表述为商业 FCD 或当地真实速度的外部验证。本阶段未下载或训练，作者须先确认数据许可及获取方式。
